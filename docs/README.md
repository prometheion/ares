# The documents of Ares

Ares is experimental, and so are these documents: they describe the engine as it
is on `main` and change with it.

## For running Ares

| Document | What it is for |
| --- | --- |
| [`user/quickstart.md`](user/quickstart.md) | Build, run the 27B or Flash-Next, a first request, logs and metrics |
| [`user/options.md`](user/options.md) | Every option, its default, and the environment, config and preset files |
| [`user/models.md`](user/models.md) | The models and weight types Ares runs, K/V formats, drafters, what was run and what it needed |
| [`user/hardware.md`](user/hardware.md) | GPUs, two cards and peer access, RAM, SSD |
| [`user/api.md`](user/api.md) | The routes and the request fields of each API, priorities, thinking, tools, images |
| [`user/features.md`](user/features.md) | What Ares does, one line each |

## For developing Ares

| Document | What it is for |
| --- | --- |
| [`OPEN.md`](OPEN.md) | What is open and in work, the order of work and the owner's decisions; brought up to date at every merge |
| [`dev/README.md`](dev/README.md) | The index of the developer documents, the tests, and where the former single architecture file went |
| [`dev/architecture/`](dev/architecture/overview.md) | How the engine works and why, one file per topic; the place to start before changing code |
| [`dev/experiments/`](dev/experiments/) | Dated measurement logs and A/B results, by topic |
| [`dev/studies/`](dev/studies/) | Studies of other engines and of the model architectures, each on its date |
| [`dev/history.md`](dev/history.md) | What was done, by date |
